## ✨ Возможности

- ⚡ **Быстро** — около 13 500 кошельков в секунду на Apple M2
- 🔒 **С проверкой** — каждое совпадение с GPU заново выводится на CPU, и только потом показывается фраза
- 🧪 **Самотест** — ядро GPU и проверка на CPU при каждом запуске сверяются с известными векторами
- 💾 **Ничего не сохраняется** — секретная фраза печатается один раз и не пишется на диск
- 🎯 **Настоящие кошельки Telegram** — фраза из 12 слов импортируется прямо в Telegram

## 📋 Требования

- Mac с GPU, поддерживающим Metal (разработка и замеры — на Apple M2)
- Xcode Command Line Tools: `xcode-select --install`
- Node.js 20 или новее

## 🚀 Быстрый старт

```sh
git clone https://github.com/CraftStick/Telegram_Wallet_Vanity.git
cd Telegram_Wallet_Vanity
./gpu/build-mac.sh
./gpu/gram-gpu abc
```

Скрипт сборки ставит зависимости Node, компилирует `gpu/gram-gpu` и запускает 5-секундный бенчмарк.

## 🔧 Использование

```sh
./gpu/gram-gpu <суффикс> [опции]
```

Суффикс — от 1 до 8 символов адреса: буквы, цифры, `_` или `-`. Регистр не учитывается, если не указать `-c`.

| Опция | Что делает |
|---|---|
| `-c`, `--case-sensitive` | Точное совпадение регистра (примерно вдвое медленнее на каждую букву) |
| `-v`, `--verbose` | Подробности запуска и строка на каждый пакет GPU |
| `-b`, `--batch <n>` | Кандидатов за один запуск GPU (по умолчанию подбирается автоматически) |
| `--benchmark <s>` | Замер скорости в течение `<s>` секунд без сохранения кошельков |
| `-h`, `--help` | Справка |

> [!TIP]
> Для долгого поиска не давайте Mac уснуть: `caffeinate -i ./gpu/gram-gpu <суффикс>`

## ⏱ Сколько ждать

Каждая буква умножает объём работы на 32 (на 64 с `-c`), каждая цифра, `_` или `-` — на 64.
При скорости около 13 500 кошельков в секунду (Apple M2):

| Букв | Попыток в среднем | Время в среднем |
|:---:|---:|---:|
| 1–2 | до ~1 тыс. | мгновенно |
| 3 | ~33 тыс. | ~3 секунды |
| 4 | ~1 млн | ~1,5 минуты |
| 5 | ~34 млн | ~40 минут |
| 6 | ~1,07 млрд | ~22 часа |
| 7 | ~34 млрд | ~4 недели |

Поиск случайный, поэтому это средние значения: половина запусков укладывается примерно в 70 % этого времени,
а каждый двадцатый длится втрое дольше. Если остановить поиск и запустить заново, ничего не теряется.

Суффикс есть только у небаунсабельного адреса (`UQ…`). Баунсабельная форма (`EQ…`) того же кошелька
заканчивается иначе.

## 🔐 Безопасность кошелька

> [!WARNING]
> Любой, кто увидит секретную фразу, получает контроль над кошельком. Не вставляйте её в чаты, заметки и скриншоты.

- Фраза печатается один раз, в терминале. Запишите 12 слов до того, как закроете окно.
- Импортируйте фразу в Telegram и сверьте адрес, прежде чем что-либо на него отправлять.
- Запускайте поиск только на компьютере, которому доверяете.

## ⚙️ Как это работает

Для каждого кандидата ядро GPU (`gpu/gram-gpu.metal`) выполняет полный вывод адреса:

1. 128 бит энтропии → фраза BIP39 из 12 слов
2. PBKDF2-HMAC-SHA512, 2048 раундов → сид
3. SLIP-0010 ed25519, путь `m/44'/607'/0'` → приватный ключ
4. Публичный ключ ed25519 (таблица для базовой точки, 32 обращения)
5. Хеш состояния кошелька для трамплина из [tg-wallet-contract](https://github.com/ton-blockchain/tg-wallet-contract)
   → адрес → сравнение суффикса

База энтропии берётся из системного генератора случайных чисел и обновляется для каждого пакета.

GPU только сообщает, какой кандидат совпал. Затем `gram-verify.mjs` заново выводит кошелёк на CPU через
`@ton/crypto` и `@ton/ton`, и фраза печатается, только если у этого независимого результата есть нужный суффикс.
